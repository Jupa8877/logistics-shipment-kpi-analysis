# Logistics Shipment Tracking & KPI Analysis

## Project Overview

This project demonstrates an Excel-based logistics shipment tracking and
performance analysis system using a dataset of 1,200 shipments.

The project tracks shipment milestones, analyzes carrier performance,
identifies shipment delays and documentation errors, and summarizes
operational performance through a KPI dashboard.

## Key KPIs

- Total Shipments: 1,200
- On-Time Delivery: 79.1%
- Average Processing Time: 4.0 Days
- Delay Rate: 15.3%
- Documentation Error Rate: 19.9%

## Analysis Areas

### Carrier Performance
Analyzed shipment delays and delay rates across UPS, FedEx, XPO, DHL,
and USPS.

### Monthly On-Time Performance
Evaluated monthly shipment performance to identify seasonality and
periods of declining service levels.

### Documentation Accuracy
Analyzed documentation error rates by shipper and over time to identify
potential process improvement opportunities.
